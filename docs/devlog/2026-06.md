# Devlog — June 2026

## June 4, 2026 — Game Redesign and Interaction System

**Video:** https://youtu.be/e6-AYbdrRIo  
**Related system:** [Interaction Fragments](../systems/interaction-fragments.md)

![Interaction prototype](../../screenshots/Image_Interaction_1.png)

### Summary

At this point, the project started transitioning from Lost Signal toward Lost in Abyss.

After building the base mechanics, the next step was to create a larger level prototype and test the scale of the world. That test showed that the previous gameplay loop did not work well enough.

The project entered a redesign phase. Some mechanics may move into the new gameplay direction, while others will be left behind.

For the new gameplay loop, a new interaction system was started. The goal was to have a scalable interactable component with interaction fragments. Each fragment represents an action that can be exposed by an object.

This iteration also used GAS and Common UI to support interaction hints for both keyboard and gamepad input.

### Next steps from this stage

- Prototype a small level to validate the new gameplay idea.
- Expand the mechanic set, starting with the most important mechanics such as rope.
