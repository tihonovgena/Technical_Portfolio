# How to Add a New System to This Portfolio

The repository should stay portfolio-first, not diary-first.

When adding a new system:

1. Add selected source files under `code/<SystemName>/`.
2. Create one page under `docs/systems/<system-name>.md`.
3. Use `docs/portfolio/system-case-template.md`.
4. Add the system to the `Best Code to Review First` table in `README.md` only if it is strong enough for a hiring reviewer.
5. Keep the devlog as supporting context only.

## Quality Bar

A system should be added to the main README only if it shows at least one of these:

- meaningful Unreal Engine architecture
- multiplayer / replication / prediction logic
- performance or optimization thinking
- data-driven design
- designer-facing workflow
- clear trade-off decisions
- production-style debugging, validation, or maintainability

If the system is only a quick prototype, keep it in the devlog until it becomes a portfolio case study.
