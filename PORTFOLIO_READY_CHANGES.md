# Portfolio-Ready Changes

This version reorganizes the repository to make it easier for a hiring reviewer to evaluate the project quickly.

## What changed

- Rewrote the root README as a technical portfolio entry point.
- Added a clear "Best Code to Review First" table.
- Reframed the project as selected public source excerpts, not a full game source release.
- Added system case studies under `docs/systems/`.
- Kept the chronological devlog, but made it secondary.
- Corrected English and reduced diary-style wording in devlog pages.
- Added a reusable system-case template under `docs/portfolio/system-case-template.md`.
- Removed `.git` from the downloadable archive.

## What did not change

- C++ source excerpts were not rewritten.
- Screenshots were preserved.
- Existing implementation facts were not invented or inflated.

## Recommended next manual step

Before publishing, review every claim in the README against the latest code you want to expose publicly.

If a system is not strong enough to defend in an interview, keep it in the devlog but do not put it in the top README table.
